# Regras de Negócio e Padrões Arquiteturais - Projetos Afesu Veleiros

## 1. Padrão de Stack
- **Backend**: Python 3.10+ (FastAPI / Uvicorn) para inteligência artificial, processamento de dados, machine learning, visão computacional e NLP.
- **Frontend**: JavaScript / React (Vite) para criar interfaces interativas, dashboards modernos, chat com streaming e suporte a voz (Web Speech API).

## 2. Padrões de Código e Didática
- O código deve ser ricamente comentado em português com explicações conceituais claras para alunos a partir de 14 anos.
- Evitar dependências desnecessárias ou de difícil instalação em máquinas de laboratório (Intel Core i5, 8GB RAM, Windows).
- Sempre incluir tratamento de erros amigável e logs explicativos.
- Manter uma estrutura modular para que cada projeto possa ser executado de forma independente ou integrado ao Portal Central do Curso.

## 3. Checklist e Acompanhamento
- Todos os projetos devem mapear seu status em relação às capacidades técnicas e socioemocionais da ementa oficial SENAI-SP (40h).
